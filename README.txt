STRUKTUR FOLDER
- index.html
- style.css

  - profil.jpeg
  - kaos-cilegon.jpeg
  - poster-bimbingan.jpeg
  - logo-lumment.jpeg
  - banner-project.jpeg

CARA MENJALANKAN
1. Ekstrak folder/ZIP ini.
2. Pastikan index.html, style.css, script.js, dan folder assets berada dalam satu folder utama.
3. Buka index.html menggunakan browser.

CARA MENGUNGGAH KE GITHUB PAGES
1. Buat repository baru di GitHub.
2. Unggah semua isi folder ini ke root repository.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu tekan Save.
6. Tunggu proses publikasi selesai. Gunakan alamat GitHub Pages yang diberikan GitHub.

CATATAN
- Website menggunakan HTML, CSS, dan JavaScript murni tanpa framework atau proses build.
- Ganti gambar di folder assets jika ingin memperbarui foto profil atau karya.
- Pastikan nama file gambar tetap sama dengan yang dipanggil di index.html, atau sesuaikan alamat src-nya.
